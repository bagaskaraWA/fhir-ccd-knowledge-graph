every shared predicate has a matching rule in silver_oracle.RULES : True

-- 2. are those 15 predicates the same function? ---------------------------
Source inspection shows the gate predicates copied verbatim from the oracle's
rules. Copied text is weaker evidence than identical behaviour, so both are
evaluated on the same feature vectors and compared.

real cohort: 876 vectors
    all 15 predicates agree on every vector
synthetic:   200000 vectors
    all 15 predicates agree on every vector

Synthetic vectors are drawn onto the boundaries every predicate tests (bmi_max, dbp, ldl_max, lvef_min, sbp, tg_max),
including missing values, so a difference in threshold or in comparison
direction would surface. Total disagreements: 0.

The gate predicate and the reference rule are therefore the SAME FUNCTION for
these 15 recommendations. Their agreement in the evaluation cannot be evidence
that the rule is clinically right; it is evidence that the two data paths
deliver the same values to it.

The observation-gate ablation is affected differently. Only value-gated and both
change between the ablation arms (eval_by_class.py), and those are exactly the
shared-predicate recommendations -- so the whole of the reported ablation gain is
measured on them. That gain is still a real change in the system's behaviour, but
the reference standard it is measured against is not an independent judge of the
rule being applied; it is an independent judge of the values fed to it.
